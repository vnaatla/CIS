# CIS (VB -> Angular migration)

## Databases
- Uses the GENESIS databases already restored on the SQL Server 2025 default instance `localhost` (Windows auth, TCP off -> shared memory `(local)`).
  See `D:\GENESIS\AGENTS.md`. CIS opens all 8: HISDB, HISDMArchive, HISWorkSheet, HISPayment, HISMaintenance, CISDB, CISWorksheet, CISPayment.
- Run sqlcmd from PowerShell (Git Bash mangles backslashes).

## Running the legacy VB6 app (MedixCIS)
- `CIS VB\` is the untouched original source (`medixcis.vbp`, Startup = Sub Main in `SubMain.bas`).
- Patched local copy: `LocalRun\Src\medixcis_local.vbp`, generated by `LocalRun\setup-localrun.ps1` (rerun it to refresh Src from `CIS VB`;
  it overwrites any edits made in `LocalRun\Src`).
  - Drops the Crystal Reports (cpeaut32 / CRYSTL32.OCX) and Outlook refs (not installed) and strips the Crystal control from 11 forms.
  - MSCOMCTL 2.2 -> 2.0 (only VS6 RTM controls are registered), Office refs pointed at Office16.
  - Writes `LocalRun\Src\SVRSuper.ini` (read from App.Path; all paths point at `D:\CIS\LocalRun\...`) and 8 UDLs into `LocalRun\CIS\Conn\`
    (UDL map: mediconnect=HISDB, mediconnectA=HISDMArchive, mediconnectWS=HISWorkSheet, mediconnectPayment=HISPayment,
    MediConnHISMaint=HISMaintenance, MediConnCISDB=CISDB, MediConnCISWS=CISWorksheet, MediConnCISPayment=CISPayment).
- Run (non-elevated, PowerShell):
  `$env:__COMPAT_LAYER='RunAsInvoker'; & 'C:\Program Files (x86)\Microsoft Visual Studio\VB98\VB6.EXE' /run "D:\CIS\LocalRun\Src\medixcis_local.vbp"`
- `/make` fails (code still references the stripped Crystal controls, e.g. frmMCOFeeListNew `cRptMCO`); `/run` works via compile-on-demand.
  Crystal report screens and the 3 email-notification screens (Outlook) error when used.
- Login: same `HISMaintenance.dbo.USR` accounts as GENESIS (local dev: DEVADMIN / Gen12345). Successful logins insert a `Tbl_USRTrack` row with SYSName='CIS'.
- The `.log` files in the source folder are stale form-load logs from the original developers, not from local runs.
